01 Motivación e intuición · Semana 09

¿Por qué «diseñar el grafo» es más importante que memorizar algoritmos?

Skiena (Cap. 5 y 6.6) enseña que el verdadero arte está en modelar grillas, estados de juegos, dependencias de cursos o transformaciones de palabras como vértices y aristas. Una vez construido el grafo, DFS y BFS resuelven casi todo en tiempo lineal O(V + E).

Enfoque 1

Matriz de Adyacencia

Espacio O(V²) · Vecinos O(V)

Solo útil si V ≤ 1.000 o grafo denso (Floyd-Warshall)

Enfoque 2

Lista de Adyacencia

Espacio O(V + E) · Vecinos O(deg(u))

Estándar para DFS, BFS, Dijkstra y grafos dispersos

Enfoque 3

Grafo Implícito (Grilla 2D)

Sin guardar aristas · O(R·C)

Usar arreglos dr[] y dc[] de 4 u 8 direcciones

02 Fundamentos teóricos · Parte I

DFS vs. BFS: Qué Garantiza Cada Recorrido

CP3 (§4.2) y CPH (Cap. 12) comparan ambos recorridos O(V + E) según la estructura auxiliar que usan (pila/recursión vs. cola).

DFS (Depth-First Search)

Explora tan profundo como sea posible antes de retroceder. Ideal para componentes conexas, detección de ciclos, Flood Fill y orden topológico.

BFS (Breadth-First Search)

Explora capa por capa (distancia 0, 1, 2…). Garantiza el camino más corto en número de aristas en grafos NO ponderados.

Flood Fill en grillas 2D

Cada celda es un vértice conectado a 4 vecinos (dr={-1,1,0,0}, dc={0,0,-1,1}) u 8 vecinos. Marcar al visitar para no entrar en ciclo.

Verificación Bipartita (2-coloreo)

Un grafo es bipartito ⇔ no tiene ciclos impares ⇔ BFS puede asignar colores {0, 1} sin conflictos entre vecinos.

03 Algoritmo y criterios de decisión · Parte II

Ordenamiento Topológico en Grafos Dirigidos Acíclicos (DAG)

Un orden topológico ordena los vértices de un DAG de modo que toda arista dirigida u → v apunte de izquierda a derecha. Hay dos algoritmos clásicos O(V + E):

AlgoritmoCómo funcionaVentaja principalCuándo elegirlo
DFS Post-OrdenAl terminar de explorar los vecinos de u, hacer order.push_back(u); al final invertir.Muy corto (6 líneas)Cuando vale cualquier orden topológico (UVa 10305)
Kahn (BFS con in-degree)Encolar nodos con grado de entrada 0; al sacar u, decrementar indeg[v] y encolar si llega a 0.Detecta ciclos (order.size() < V) y permite min-heapCuando piden el orden lexicográficamente menor (UVa 11060)

Resumen conceptual de la semana

  • Representación: Lista de Adyacencia vs. Matriz de Adyacencia vs. Lista de Aristas.
  • DFS (pila/recursión): componentes conexas, detección de ciclos y tiempos de entrada/salida.
  • BFS (cola): distancias mínimas en grafos no ponderados y verificación bipartita (2-coloreo).
  • Orden Topológico en DAGs: DFS en post-orden invertido y algoritmo de Kahn (BFS con grados de entrada).

05 Plantilla reutilizable (Notebook ICPC)

Flood Fill 2D en 4/8 direcciones (C++17 / Java / Python 3)

Usa el selector superior para alternar entre C++17, Java y Python 3. Puedes copiar el bloque con un clic para probarlo en clase.

#include <vector>
#include <string>
using namespace std;

const int dr[4] = {-1, 1, 0, 0};
const int dc[4] = {0, 0, -1, 1};

// Cuenta y marca el tamaño de una componente conexa de carácter `target`
int floodFill(int r, int c, vector<string>& grid, char target, char mark) {
    int R = (int)grid.size(), C = (int)grid[0].size();
    if (r < 0 || r >= R || c < 0 || c >= C || grid[r][c] != target) return 0;
    grid[r][c] = mark;
    int cnt = 1;
    for (int d = 0; d < 4; d++)
        cnt += floodFill(r + dr[d], c + dc[d], grid, target, mark);
    return cnt;
}
static final int[] dr = {-1, 1, 0, 0};
static final int[] dc = {0, 0, -1, 1};

// Cuenta y marca el tamaño de una componente conexa de carácter `target`
static int floodFill(int r, int c, char[][] grid, char target, char mark) {
    int R = grid.length, C = grid[0].length;
    if (r < 0 || r >= R || c < 0 || c >= C || grid[r][c] != target) return 0;
    grid[r][c] = mark;
    int cnt = 1;
    for (int d = 0; d < 4; d++)
        cnt += floodFill(r + dr[d], c + dc[d], grid, target, mark);
    return cnt;
}
from collections import deque

def flood_fill_bfs(sr, sc, grid, target, mark):
    R, C = len(grid), len(grid[0])
    if grid[sr][sc] != target:
        return 0
    grid[sr][sc] = mark
    q = deque([(sr, sc)])
    cnt = 0
    while q:
        r, c = q.popleft()
        cnt += 1
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C and grid[nr][nc] == target:
                grid[nr][nc] = mark
                q.append((nr, nc))
    return cnt

Fácil BFS · Verificación de Grafo Bipartito Tiempo: O(V + E) Espacio: O(V + E)

Enunciado resumido

Dado un grafo conexo no dirigido de n < 200 nodos y l aristas, determinar si se pueden colorear los vértices con 2 colores de modo que ningún par de vértices adyacentes comparta color.

Idea clave y trampas a evitar

07 Solución verificada · Problema UVa #1

Código completo: UVa 10004 — Bicoloring

Compilado y verificado contra el Sample Input oficial en C++17 (-O2 -Wall), Java y Python 3.

#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    while (cin >> n && n != 0) {
        int l;
        cin >> l;
        vector<vector<int>> adj(n);
        for (int i = 0; i < l; i++) {
            int u, v;
            cin >> u >> v;
            adj[u].push_back(v);
            adj[v].push_back(u);
        }

        vector<int> color(n, -1);
        bool ok = true;
        for (int s = 0; s < n && ok; s++) {
            if (color[s] != -1) continue;
            queue<int> q;
            color[s] = 0;
            q.push(s);
            while (!q.empty() && ok) {
                int u = q.front(); q.pop();
                for (int v : adj[u]) {
                    if (color[v] == -1) {
                        color[v] = 1 - color[u];
                        q.push(v);
                    } else if (color[v] == color[u]) {
                        ok = false;
                        break;
                    }
                }
            }
        }
        cout << (ok ? "BICOLORABLE.\n" : "NOT BICOLORABLE.\n");
    }
    return 0;
}

08 Segundo problema resuelto · Problema UVa #2

UVa 10305 — Ordering Tasks Fácil

Enunciado e idea (O(V + E))

Hay n ≤ 100 tareas numeradas de 1 a n y m relaciones de precedencia (i, j) indicando que la tarea i debe ejecutarse antes que la tarea j. Imprimir un orden válido de ejecución (termina con 0 0).

Clave: Aplicamos el algoritmo de Kahn: calculamos indeg[1..n], encolamos todas las tareas con indeg == 0, y vamos liberando sus sucesores. Maneja naturalmente tareas aisladas (m = 0) y múltiples componentes.

Sample Input
5 4
1 2
2 3
1 3
1 5
0 0
Sample Output
1 4 2 5 3
PDF UVa 10305 ↗ Enviar en VJudge ↗ 
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    while (cin >> n >> m && (n || m)) {
        vector<vector<int>> adj(n + 1);
        vector<int> indeg(n + 1, 0);
        for (int i = 0; i < m; i++) {
            int u, v;
            cin >> u >> v;
            adj[u].push_back(v);
            indeg[v]++;
        }
        queue<int> q;
        for (int i = 1; i <= n; i++)
            if (indeg[i] == 0) q.push(i);

        vector<int> order;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            order.push_back(u);
            for (int v : adj[u]) {
                if (--indeg[v] == 0) q.push(v);
            }
        }
        for (int i = 0; i < (int)order.size(); i++) {
            if (i) cout << ' ';
            cout << order[i];
        }
        cout << '\n';
    }
    return 0;
}

import sys
from collections import deque

tokens = list(map(int, sys.stdin.read().split()))
idx = 0
out = []
while idx < len(tokens):
    n, m = tokens[idx], tokens[idx + 1]; idx += 2
    if n == 0 and m == 0:
        break
    adj = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)
    for _ in range(m):
        u, v = tokens[idx], tokens[idx + 1]; idx += 2
        adj[u].append(v)
        indeg[v] += 1
    q = deque(i for i in range(1, n + 1) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(str(u))
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    out.append(" ".join(order))
print("\n".join(out))
09 Errores frecuentes y trabajo independiente

Trampas típicas y taller de la Semana 09

Trampas frecuentes (evita WA / TLE)

  • En BFS, marcar el nodo como visitado al SACARLO de la cola en vez de al ENCOLARLO: puede encolar el mismo nodo múltiples veces y causar TLE/MLE.
  • Asumir que el grafo es conexo: siempre iterar for (int i = 0; i < V; i++) if (!vis[i]) ... para cubrir todas las componentes.
  • En grillas grandes (> 10⁵ celdas), un DFS recursivo puede provocar Stack Overflow (RTE), especialmente en Python; usa BFS iterativo.
  • Confundir grafos dirigidos con no dirigidos al agregar aristas (en no dirigidos siempre agregar u→v y v→u).
